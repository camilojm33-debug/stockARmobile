Guía rápida

Empezá a usar StockArmobile

Una ruta simple para configurar tu comercio y operar todos los días.

Hacer una venta
Ruta recomendada: configurá tu empresa → cargá productos → agregá clientes → configurá caja/cobros → hacé la primera venta → revisá reportes.

1. Productos

Cargá nombre, precio, stock, código y categoría.

2. Clientes

Registrá clientes para historial y ventas recurrentes.

3. Caja

Abrí caja, registrá movimientos y controlá el cierre.

4. Primera venta

Elegí productos, cliente y medio de pago y confirmá.

Operación diaria

01
Revisá stock
Controlá existencias y productos con stock bajo antes de vender.
02
Vendé
Usá la venta rápida o el scanner para cargar productos.
03
Presupuestá cuando corresponda
Un presupuesto puede quedar pendiente, ser aceptado o convertirse posteriormente en venta.
04
Controlá caja
Registrá ingresos y egresos y revisá el cierre del día.
05
Revisá información
Usá dashboard, reportes y métricas para detectar cambios en ventas, stock y clientes.

Presupuestos y pedidos

Usá presupuestos cuando todavía no corresponde registrar una venta. Revisá siempre el estado antes de interpretar la operación como confirmada.

Pendiente
Todavía no está confirmado.
Aceptado
El cliente aceptó el presupuesto, pero no significa por sí solo que exista una venta.
Pago
El pago puede estar pendiente, en proceso o aprobado.
Venta confirmada
La operación fue convertida correctamente en una venta.

Cobros y Mercado Pago

Cuando uses un pago online, distinguí claramente entre el estado del pago y la confirmación de la venta.

  • Pendiente: todavía no se confirmó.
  • En proceso: Mercado Pago continúa procesándolo.
  • Aprobado: el pago fue aprobado.
  • Confirmado: el pedido fue convertido correctamente en venta.
